# Club Management System

## Overview
A Java-based university club management system that streamlines the management of student clubs, committees, members, events, and rewards.


## Features
- Member management
- Committee management
- Event management
- Event reports
- Member reports
- Rewards calculation
- GUI
- File serialization
- Exception handling
- Linked lists
- Recursion

## Technologies
- Java
- Java Swing
- Object Serialization
- Linked Lists
- Git & GitHub
